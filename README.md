Assignment 2 Report

 Design Choices
The visual mockup was designed for a NASA APOD website with a clean and modern space-inspired layout. The design focuses on highlighting the Astronomy Picture of the Day as the main feature of the homepage.

 Colour and Font Selection
The colour palette uses dark tones such as black, navy, and white to match the space theme and create strong contrast. Simple and readable fonts were selected to keep the content clear and professional.

 Layout and Responsiveness Decisions
The layout was designed for desktop, tablet, and mobile screen sizes. On larger screens, content is arranged in wider sections, while on smaller screens it stacks vertically for better readability and usability.

 Usability and User Experience
The mockup improves usability by keeping navigation simple, making the featured image the main focus, and ensuring the content is easy to read across different screen sizes.
